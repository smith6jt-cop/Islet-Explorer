## Current app behavior (unstaged)

- The Trajectory Y axis defaults to **cell-type ratio**, with the numerator
  counted in **core**. The tab no longer displays the long axis/rank notes
  or the zero-percentage callout.
- The `Cells per islet` slider uses five-cell steps. It is a *draft* range:
  only **Recalculate trajectory** applies it. The fit, PAGA layout, plots,
  CSV filenames and provenance continue to use the previous applied range
  until that button is pressed. The loaded and fitted islet counts sit beside
  the slider. Default range 10-1,902 fits 2,310 of 5,214 islets; 2,904 have
  fewer than 10 core cells. Changing the Y measure does not refit the axis.
- The large pseudotime scatter uses smaller default dots (point-size control
  1.5), 850 px height and increased **vertical display-only** jitter (8% of
  the Y range). Its X jitter remains 1.2% of the pseudotime extent. LOESS
  trends and hover values use unjittered data; plotting displacement must
  not be mistaken for measured abundance. Point clicks still resolve islets.
- The multi-feature heatmap initially checks INS, GCG, SST, CHGA, CD45, CD31,
  panCK and B3TUBB. All 31 markers remain selectable.
- Trajectory data loading now uses Shiny progress feedback and says
  **Loading data** in the scatter's transient uninitialized state, rather
  than prematurely reporting no trajectory. Progress-bar timing was not
  separately instrumented in a cold browser session.
- Plot, Trajectory, Viewer and Spatial have larger (24 px) upper-right help
  icons. The hidden Statistics and Inflammation tabs use the same shared
  helper if re-enabled. Plot's instructions, Trajectory's click instruction,
  Spatial's zoom instruction and each tab's phenotype-rules link are behind
  those disclosures. Trajectory's secondary View controls are collapsed on
  initial load to reclaim plot space; Data controls stay visible.
- Trajectory's UMAPs stack vertically. The segmentation card remains mounted
  with an empty state until an islet is selected, then displays a full-width
  map with its controls and composition below. The multi-feature heatmap is
  full width below the scatter/UMAP row; this removed a long empty right
  column. The active-tab guard in `mod_trajectory_server.R` still prevents
  duplicate root-level segmentation output IDs across Plot and Trajectory.
