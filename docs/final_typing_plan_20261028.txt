WORDS USED
- Background peak: the most common value of a marker among the image's cells that do not carry it.
- Level: the cutoff above which a cell counts as positive for a marker, set per image from that
  marker's background by the method its marker class passes (e.g. background peak + 3 widths).
- Check: a test of a marker's level against something known without it (its objects, or biology
  such as "every T cell carries CD45"); a marker is used only if it passes in every image.
- Defining marker: places a cell in a compartment by itself (e.g. CD45 -> hematopoietic).
- Shared marker: carried by several compartments, so it only adds evidence (e.g. VIM).
- Canary check: do a cell's positive markers point to one compartment? Two = ambiguous unless one wins
  by 2 markers; three or more = suspected doublet.
