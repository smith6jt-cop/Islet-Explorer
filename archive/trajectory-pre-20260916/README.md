# Historical trajectory implementations

These files preserve the earlier ND/INS-root, composition and size-split
trajectory methods. They are not used by the schema-2 candidate. Relative
paths in these snapshots assume their original locations; use the frozen
release/source checkout to reproduce historical results. Do not execute them
against the all-donor candidate or overwrite original scientific files.

Current preparation and fixed diffusion defaults are documented in
[`scripts/research/README.md`](../../scripts/research/README.md).
